TaskSwift
A simple and responsive task tracker built with React and Vite.

Overview
Lightweight practice project for managing daily tasks. Add, view, and delete tasks with a live counter and clean empty state. Focused on core React fundamentals and a responsive UI.

Features
• Add new tasks
• Delete tasks
• View all tasks
• Real-time task counter
• Empty-state message
• Responsive interface

Tech Stack
React • Vite • JavaScript (ES6+) • CSS3

Installation
git clone https://github.com/ak0145-max/taskswift.git
cd taskswift
npm install
npm run dev
